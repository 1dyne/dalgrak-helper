# 두 번 눌러서 켜기

터미널 명령을 치지 않고 달그락 연결 앱을 켜는 파일이에요.

| 내 컴퓨터 | 누를 파일 |
|---|---|
| 맥 | `달그락 연결 앱.command` |
| 윈도우 | `달그락 연결 앱.bat` |

- 이 폴더를 통째로 옮기지 말고, 내려받은 폴더 안에 그대로 두고 눌러주세요(바로 위 폴더의 프로그램을 실행해요).
- 맥에서 처음 누르면 "확인되지 않은 개발자" 경고가 뜰 수 있어요. 파일을 오른쪽 클릭 → 열기를 한 번 하면 다음부터는 바로 열려요.
- Node.js가 없으면 설치 페이지가 열려요. LTS 버전을 설치한 뒤 다시 눌러주세요.
- 한 번 켠 뒤 터미널에 `dalgrak-helper install-shortcut`을 치면 바탕화면에 바로가기가 생겨요.
